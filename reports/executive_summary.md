# Executive Summary: Meta Ads Efficiency Analysis

> **Scope and honesty note.** This is a methods demonstration on the public
> Kaggle "sales conversion" dataset — **1,143 ads** from a single advertiser.
> It is large enough to show the SQL + modelling + experiment-design workflow
> end to end, and large enough for the descriptive findings below to be solid,
> but **too small to support production ML claims**. The predictive models are
> included to demonstrate technique, not to assert field-ready accuracy. Every
> number here is regenerated by `python scripts/compute_summary.py`; if the doc
> and the script disagree, the script wins.

## Problem
Which audience segments spend budget without returning proportional approved
conversions, and how much budget is reallocatable toward efficient segments?

## Key findings (measured, reproducible)

### Overall performance
| Metric | Value |
|---|---|
| Ads | 1,143 |
| Total spend | **$58,705** |
| Approved conversions | **1,079** |
| Overall CPA | **$54.41** |
| Average CTR | 0.018% |
| Conversion rate (approved / click) | 2.83% |

### The headline inefficiency
- **559 of 1,143 ads (48.9%) produced zero approved conversions**, consuming
  **$14,754 — 25.1% of total budget.** This is the single reallocatable pool
  and the core finding of the analysis.

### Demographic efficiency gradient
- **CPA rises monotonically with age**: 30–34 **$30.88** → 35–39 $53.68 →
  40–44 $68.17 → 45–49 **$99.76**. The oldest bracket costs **3.2×** the
  youngest per approved conversion.
- **Men convert cheaper than women**: CPA $41.44 (M) vs $69.70 (F).

### Interest-segment variance
- Across 40 interest segments, CPA ranges **$18.69 → $107.97** (median $56.10,
  coefficient of variation 0.42) — a 5.8× spread, the dispersion a reallocation
  strategy exploits.

## Recommendation
Reallocate the 25.1% of budget currently spent on zero-conversion ads toward
the sub-median-CPA segments (younger brackets, male audiences, the cheapest
interest segments).

**What the data does and does not license us to promise:** the *reallocatable
budget* (25.1%) is measured. The *resulting lift* is **not** measured — it
depends on whether efficient segments scale without rising CPA, which is a
causal question this observational dataset cannot answer. The budget simulator
(`R/09_budget_simulator.R`) therefore reports a **range under an explicit
constant-CPA assumption**, and the A/B design (`R/10_ab_test_design.R`,
`reports/experiment_design.md`) is the honest way to validate it. No single
headline "X% lift" is claimed, because this dataset cannot defend one.

## Next steps
1. Run the pre-registered A/B test (control = current allocation, treatment =
   reallocated) to get a *causal* lift estimate.
2. Re-estimate CPA elasticity as efficient segments scale, to check the
   constant-CPA assumption.
3. Re-run this summary on live campaign data via `scripts/compute_summary.py`.
